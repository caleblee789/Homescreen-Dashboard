# AnkiWeb theme previews with default future indicators off

Eight selected Month views captured in a fresh, sync-disabled Anki 26.8.1
profile using the published 1.8.7 package (`8b617376`). All 25 installed
package members match the archive. The isolated collection has 1,184 seeded
review-history rows; the dashboard uses the existing populated presentation
fixture with 186 studies today, 1,214 in the last week, and a Pediatrics review
event.

Every captured view has zero future due indicators, no Due cards legend,
populated review fills, and a visible event marker and summary. The eight
frames were taken directly from the isolated native QMainWindow because the
screen compositor was displaying another application. These images support
the cropped dashboard previews; they do not establish host placement across
macOS Spaces or a full release acceptance result.

The original Anki process remained running. The isolated process exited after
capture. Source frames are retained here unchanged; gallery crops and labels
are documented in `docs/images/1.8.7/theme-gallery-sources.json`.
